--------------------------------
[ ] lsblk -> identify SRC, DST
    SRC: _____  DST: _____

      bs=4M status=progress \
      conv=fsync ; sync

    path: ____________________

        enable_uart=1

    (config.txt is the ONLY

[E] CUTOVER TO Pi 3B+
--------------------------------
[ ] PSU = SAME 5V 5A barrel jack
    -> WAGO -> A1 (Pi) + printer
    POWER UNCHANGED from Pi 5.
    Do NOT switch to micro-USB
    (would back-feed A1).
[ ] Insert SD into Pi 3B+
[ ] Plug A1 only (pins 2-4-6)
    pos-1 mark to pin-1 corner
[ ] Power on at the wall
[ ] Wait ~60 s for boot

      grep Model

[ ] ls -l /dev/serial0
    -> "-> ../ttyAMA0"

POWER NOTE
--------------------------------
- Shared 5V/5A barrel jack is
  UNCHANGED. 3B+ draws less than
  the Pi 5, so MORE printer
  headroom, not less.
- Native micro-USB 2.5A is a
  FALLBACK only, used only if
  get_throttled goes non-zero
  -- and then you REMOVE A1 and
  power the Pi via micro-USB
  alone. Never run both.
