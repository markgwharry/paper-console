 PC-1 MIGRATION  Pi5 -> Pi3B+
 Field checklist  v1
 See MIGRATION_3BPLUS.md
================================

[A] PRE-FLIGHT (on Pi 5)
--------------------------------
[ ] sudo systemctl stop \
      pc-1.service \
      pc1-storage-guard.timer
[ ] cd ~/paper-console
    git status  --> clean?
[ ] vcgencmd get_throttled
    baseline: ________________
[ ] tailscale status | head -2
    IP: ______________________
[ ] sudo shutdown -h now
[ ] Wall PSU OFF, wait 10 s

[B] UNPLUG  (note pos-1 marks)
--------------------------------
[ ] A2  printer data  pins 8-14
[ ] B   button        pins 20-22
[ ] C1  dial odd row  29-39
[ ] C2  dial even row 30-40
[ ] A1  power         pins 2-6
[ ] Remove SD card
    Set aside = ROLLBACK

[C] CLONE SD CARD (on host PC)
--------------------------------
[ ] lsblk -> identify SRC, DST
    SRC: _____  DST: _____
[ ] sudo dd if=$SRC of=$DST \
      bs=4M status=progress \
      conv=fsync ; sync
[ ] Mount clone boot partition
    path: ____________________

[D] EDIT config.txt
--------------------------------
[ ] Run prepare-for-3bplus.sh
      ./prepare-for-3bplus.sh \
        <mount>
    OR apply manual diff:
      move dtparam=uart0=on
        from [all] to [pi5]
      add [pi3+]:
        enable_uart=1
        dtoverlay=disable-bt
[ ] Eject SD cleanly

[E] CUTOVER TO Pi 3B+
--------------------------------
[ ] PSU = 5V 2.5A micro-USB
    (NOT the Pi5 USB-C brick)
[ ] Insert SD into Pi 3B+
[ ] Plug A1 only (pins 2-4-6)
    pos-1 mark to pin-1 corner
[ ] Power on at the wall
[ ] Wait ~60 s for boot

[F] VERIFY BEFORE PLUGGING
    THE PRINTER
--------------------------------
[ ] ssh pc-1@pc-1.local
[ ] cat /proc/cpuinfo |
      grep Model
    -> "Raspberry Pi 3 Model B+"
[ ] ls -l /dev/serial0
    -> "-> ../ttyAMA0"
    (NOT ttyS0, NOT ttyAMA1)
[ ] dmesg | grep -i pl011
    -> ttyAMA0 at MMIO ...
[ ] ls /dev/gpiochip0
    -> exists
[ ] vcgencmd get_throttled
    -> 0x0
[ ] systemctl status pc-1
    -> active (running)
[ ] curl -sI http://localhost/
    -> HTTP 200
[ ] hostname  ->  pc-1
[ ] tailscale status
    -> same IP as baseline

  If serial0 != ttyAMA0:
    STOP. Re-check config.txt
    Do NOT plug A2 yet.

[G] RECONNECT HARDWARE
--------------------------------
[ ] sudo shutdown -h now
[ ] PSU OFF, wait 10 s
[ ] Plug A2 printer data
    (pos1 -> pin 8 = Pi TX
     -> printer RX)
[ ] Plug B button
[ ] Plug C1 dial odd
[ ] Plug C2 dial even
[ ] Power on

[H] FUNCTIONAL TEST
--------------------------------
[ ] Web UI loads
[ ] Dial each position 1-8
    log shows selections
[ ] Button short press = print
[ ] Button 5s = Quick Actions
[ ] Dense raster print
    (QR or Sudoku)
[ ] vcgencmd get_throttled
    still 0x0 under load?

[I] STABILISE
--------------------------------
[ ] 24 h soak test
[ ] No reboots in journalctl
[ ] Original SD: store sealed
    >= 1 release cycle
[ ] Then wipe Pi 5 SD for
    its next purpose
